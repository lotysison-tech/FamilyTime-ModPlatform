# FamilyTime Mod Platform

An unofficial community-made mod platform for FamilyTime.

## Compatibility

- FamilyTime Build 37
- DX11 and DX12
- Platform version: 0.20
- Multiplayer module: 0.65 (experimental)

## Download

Download the latest installer ZIP from the **Releases** section.

## Installation

1. Download the latest installer ZIP from the **Releases** section.
2. Extract it into the game folder.
3. Open `Install-BepInExModPlatform.bat` and run it.
4. Start the game.

## Important

- Multiplayer is experimental. Only connect to people you trust.
- Do not post your IP address or access code publicly.
- Back up your game files before installing mods.
